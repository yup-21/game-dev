# PJ-03 第一轮视觉/几何审核

## 通过的方向性检查

1. 与 PJ-02 v02 采用同一弱透视斜俯视角，门店为粉墙黛瓦、木檐与青灰石路，没有将长街缩为城市俯瞰图。
2. 画面由西到东连续三段，每段 1600×1000，合并后 4800×1000；单一水平卷屏方向，人物的 200 世界 px 尺度不随 X/Y 改变。
3. 西段包含可识别的城西水闸/船埠；中段保留锻炉与药草铺门前空间；东段通往十字路。

## 未通过/未执行

- **接缝不是逐像素无缝：** X=1600、3200 存在建筑立面重复、铺石纹路重启、个别树叶位置跳变。原始图像输出各自重绘，统一 1600×1000 分辨率不能消除该问题。
- **与十字路口出口未精配：** PJ-03 east 设计脚点对应 PJ-02 west，但二者图边前景房檐、路牙高度要重绘/连接测试，不能在无图层的情况下声称无缝。
- **可走地面未签核：** 目前地面概念图从 Y≈550 起较宽，近景建筑屋顶侵入 Y≈800 以上局部区域；未来需真正分层遮挡和 24px 脚点区域验证，不能直接把整块青石当 walkable。
- **门洞与角色尺度未实测：** 生成文字约束不会替代 200px 测试人物叠图和 Godot 试玩。
- 独立 `background` / `ground` / `foreground` 及真实 Alpha 尚无，因此本次只是概念母版而非可运行地图。

## 下一步

局部修复接缝及与 PJ-02 v02 的道路高度 → 生成同画布分层并验证 Alpha → 原生 Resource 明确记录世界边界、出入口与几何 → Godot 真实 GUI 双分辨率验收。未达门槛时只保留 candidate。
