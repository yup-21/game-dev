# 原创武学卡牌视觉资产（2026-10-30）
本目录 8 张卡面以及青玉纹章为本项目独立绘制的 SVG 矢量素材，未复制第三方商业游戏素材、角色或 UI。
- card_probe: 探锋／刺击；card_sunder: 重锋／破势；card_step: 轻功；card_guard: 防御化劲
- card_change: 变招与截势；card_combo: 连携；card_breath: 内息调息；card_clash: 交锋
- jade_seal: 独立剑山青玉纹章
所有 SVG 均无文字，供 Godot 4.x 导入并由 GDScript 通过 Texture2D 引用。
角色、CTB、牌面合法性、出牌费用和连携数据依旧从 BattleModel 获取；本目录仅包含渲染资源。
原创卡面是设计版本一；今后可逐图替换为同画幅高精度手绘 PNG，保持资源映射契约。
