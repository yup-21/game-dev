# 新框架美术候选集成 · 待审记录（2026-11-01）

## 合并边界

- **基线**：main 上 PR #87 已合入的 Godot 原生 Resource / 章节场景 / VFX 管线。
- **吸收**：PR #82（首批试制资源）、#83（角色/地图运行时绑定）、#84（分层预览与导入预检）、#85（第一章完整角色和破庙分层）、#86（旧缓存及映射滞后修复）。已合并入 #85 的后续章节资源改动一并保留。
- **不吸收**：早期旧框架分支及 PR（历史 UI/战斗架构、旧资源注册核心、旧 JSON 替代运行时）；#88 属重复修复。
- 新图片均视为 **candidate / review_required**，美术状态和权属记录不得因技术合并擅自改为 approved。

## 重叠功能的取舍

| 争议点 | 本次统一实现 | 保留/退出边界 |
| --- | --- | --- |
| 角色立绘、动作图 | 运行时按原生 `WuxiaCharacterDefinition` 和 `WuxiaActorAnimationProfile` 取图，不让旧 AssetRegistry 覆写 | 旧静态素材继续保留作回退；生产覆盖逐人验收后再分批退场 |
| 战斗场景图 | `WuxiaSceneArtProfile` 原点一致的 background/ground/foreground/weather，取消旧地图旋转与缩放 | 非迁移地图继续走现有兼容路径 |
| 剧情场景图 | 保留 main 的 `WuxiaChapterSceneDefinition.scene_art` 原生 Resource 合同；增加可裁剪前景、可开关天气和可选 `story_preview` | 单张旧 WebP 只作紧急回退，待人工定稿后另 PR 清退 |
| 导入与预览 | 保留 #87 新导入器（章节原生合同、VFX 变帧、事务回退），合入 #84/#86 的预检、当前绑定可见性、分层预览及动作 Profile 模板 | 不恢复早期的旧编排/导入契约 |
| 回退与审核 | 保持可回滚的文件备份、导入事务、旧占位图；候选先进入资源卡进行技术验证 | 不删除旧资源，不自动批准不一致图；人工审核后逐批移除回退 |

## 合并前机器核验

- Godot Headless Editor import / 构建；
- 两个试制角色与雨夜断桥四层绑定；
- 第一章六名角色、伤者肖像、破庙场景的原生运行检查；
- 无效导入路径、素材尺寸与 Alpha 预检；

- 旧主线已有的 VFX、章节、内容、战斗与 UI 回归测试。
