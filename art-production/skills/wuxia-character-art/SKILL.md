# 武侠角色美术与动画工作流

## 必读合同与素材边界

- 开始前读取 `art-production/standards/ART_PRODUCTION_STANDARD.md` 与 `art-production/standards/SPRITE_ANIMATION_QA.md`；设计分镜或 AI 生图时按需阅读 `art-production/prompts/ART_STYLE_AI_PROMPTS_V1.md` 的 §3、§5.1、§5.2。**绘图只发对应短模板、获准参考图和本动作变量**；不叠加整份规范、全局长风格词或负面词表。脚点语义和自动动作分帧不能靠 AI 保证。
- 读取 `art-production/templates/asset-work-order.md`，在 `art-production/candidates/<asset-type>/<asset-id>/` 留候选工作单、真实提示词与目标原生 Resource。来源可记录对应提示词/Resource，不强制额外模型、seed 或审批字段。
- 资产管理只有 `candidate` 与 `in_use`：技术预检不会批准画面；未完成视觉验收不覆盖当前绑定。Godot 运行内容仍仅来自 `.tres` 与 Content Manifest，离线 CSV/JSON 不成为运行时源数据。

## 执行流程（每一阶段可返工，不跳闸）

1. **建立 AI 身份与武器基准**：从当前角色获准设定读取 `weapon_contract`：有无武器、类型、数量、尺寸、持手、单双手握持、佩挂位置，以及动作是否允许换手/拔收武器；无武器角色要明确 `none`。用同一设定生成完整侧视战斗姿势基准图，初筛头身比、手绘武侠风格、服饰、鞋和武器配置，必要时人工确认。**不能给所有角色默认单手剑**；同一角色的同一套装备/武器外观动画应跨帧一致，明确编排的握法变化必须有过渡帧。角色换装备需要适配的新动画候选或已验证的兼容动画，不能靠角色 ID 硬编码默认武器。锁定设定身高 `height_m`，自然站姿高度 `round(height_m×100)` 源像素（100–220px）。**由 Agent 根据身高、武器和全部动作最大伸展范围先选定整角色唯一规格**：放得下则选 **328×256 普通档**，不够再选 **384×288 高个档**，两档均不够须明确专用规格或停止；**不可让生图模型判断“高个”或选择格子**。再锁定 90° 侧视、角色比例、地线和光照；以统一待机地面根投影 O=(0,0) 为跨动作逻辑原点（+x 右、+y 下），并确定其在每个格内的**同一整数像素坐标**，保持跨动作一致，不能逐帧重定中心。左右镜像不代表四方向完成。
2. **先分镜，帧数由动作决定**：分别规划 `idle/walk/run`、四种适配角色武器的攻击、`skill/evade/guard/hit/defeat` 共 12 组；`evade` **固定向后**，通过 `evade_style` 选择后撤步（默认）、后滑步、后翻滚或后跃，均需落地复位且保留后撤位移；调用 §5.2 **简版分镜提示词**，由关键姿势与必要间帧确定 N，不默认 8 帧、不为网格凑帧。按 [精灵动画 QA 合同](../../standards/SPRITE_ANIMATION_QA.md) 检查帧序、承重、根位移与相邻帧衔接；循环动作闭合，其他动作收尾与待机兼容（倒地除外）。仅异常及最终样片人工复核。
3. **锁参后短提示词生成多帧 Sheet**：Agent 先确定动作 `action_id`、装备、**逐帧局部姿势**、真实 N、C×R、整角色 W×H、源身高像素、格内根点 `(root_x_px,root_y_px)`，计算整图 `sheet_width_px=W×C`、`sheet_height_px=H×R`。将 §5.1 的全部占位符替换为唯一确定值，附获准基准图再调用生图；**不把世界位移或运行时 `root_offsets` 写进生图提示词**。当前生图接口没有独立的格数/精确像素尺寸参数，**C×R 只能作为生图布局指令**；真实 `columns/rows` 必须在候选 Resource/导入器另行声明并验收。完整动作放不下由 Agent 分为已编号时间段；失败由 Agent 定向修订重发。**不向绘图模型发送 Skill 正文、验收清单或重复反向词**。
4. **根据预先声明的网格拆格，再逐动作验收**：程序仅按 `C/R/格宽高` 机械切分多帧 Sheet，不使用不可靠的 AI 动作帧识别；检查 Sheet 宽= W×C、高= H×R、人物自然站姿高度= `round(height_m×100)`、实际有内容格数与分镜 N 匹配、填充按行序、空白格全透明，以及每格四边可测真 Alpha 边距 **至少 8px**（尽量 16px）。**任何一格触边、越格、裁切、相互侵入或帧数/顺序无法确认时，拒绝该 Sheet**，重新生成该动作或有问题的连续多帧片段，不以裁切/重排掩盖缺失像素。通过几何后依序拆成原像素帧预览动作连续性、循环/复位和同一角色/武器/O；AI 视觉只初筛明显异常，不声称可靠识别真实承重脚。仅疑难与最终少量样片人工复核，预检结果仍记录在候选工作单。
5. **生成时约束承重、移动另记**：提示词只写支撑脚、接触地线、前进/后撤的**姿势意图**，保持同一人物逻辑 O、源像素比例和地线，不在各格烘焙整人前冲/后退。Agent 在分镜另记世界移动计划；Godot `WuxiaActorAnimationClip.root_offsets` 仅用于 Sprite2D 局部表现，**不得直接复制分镜世界位移**，避免与控制器双重移动。AI 视觉只用于初筛，脚滑疑难才人工判断；脚点编辑器无法自动识别真实承重脚、动作帧或位移。
6. **合格动作再合图（P0 硬门槛）**：仅收集第 4 步已经验收的多帧 Sheet 拆格结果；程序按共享 O 锚点与**局部姿势**计算联合非透明范围、已选共同 W×H 格子和至少 8px 安全边距，原像素装配运行时 Atlas。世界移动计划另外保留，不烘焙进 Atlas。必须保留 `action_id -> ordered absolute frame_indices` 与真实帧数，不能补重复帧、错序或跨动作混索引。再次逐格断言至少 8px 透明留白、零越格/零重叠、空格透明及索引合法；不通过就重生源 Sheet；若须由普通档改为高个档，须明确切换后重制该角色全部动作，不能在打包时静默扩格，**不得用裁切、逐帧居中或缩放伪装修复**。客观几何通过后才能继续 Godot 验收。
7. **按 12 组运行时动作接入**：按 `idle/walk/run/attack1/attack2/attack3/attack4/skill/evade/guard/hit/defeat` 配置原生 `WuxiaActorAnimationClip.action`；四套攻击在目录和动作 ID 上保持固定编号，但具体打击分镜由本角色 `weapon_contract` 决定，直刺/下劈/横斩/蓄力重击仅为单剑示例。`combo` 是已配置攻击的衔接，不另画固定连携动作；旧 `move/attack/combo` 仅在存量 Profile 中显式存在时使用，不允许运行时代替缺失新 Clip。配置 `WuxiaActorAnimationProfile` 或独立 Clip Atlas、1–256 帧/动作及 1–64 行列；逐帧节奏写入 `frame_durations`，**只有需要 Sprite2D 局部表现位移时才填写世界像素单位的 `root_offsets`，普通非循环 Clip 末帧必须归零**；真实世界移动另由控制器实现/验收。不能把离线 CSV 当成自动生效配置。技能绑定一个指定动作，并以 VFX Cue 对齐有效帧；倒地停止在最终姿态。
8. **双阶段验收并保存证据**：首先验收**每次生成的多帧 Sheet** 的 C×R 网格尺寸及已选 W×H 档、100 源像素/米的人物身高、逐格 Alpha 边距、非空格总数=N、无跨格侵入及正确播放次序；逐动作再审身份/武器/O、有效间帧、循环闭合或姿态复位。其次验收**最终打包 Atlas** 的统一格子、零越界、索引与 Godot Resource 加载。完整 12 组还需检查跨动作衔接及实际运行位移是否重复叠加；AI 视觉不能证明真实支撑脚，Godot 核对速度、200 世界像素、有效窗口与导出。仅疑难及最终少量样片人工复核，未测试不报通过。

## 停止条件

- 身份或武器变化、源帧截断、关键姿势错误、持续视频闪烁：回到第 3–4 步重制，不用自动对齐掩盖。
- 生成结果有双剑、错误侧视、身份漂移、关键姿势错误时先自动重生成；不能靠抠图/提高 FPS/位置调整掩盖。**任何帧格侵占邻格、透明边距不足或裁切**都自动拒绝，并回源重画；若已选格不够，须明确改为高个档并统一重生成。脚点语义无法确认时保留 candidate，仅异常情况要求人工复核。
- Godot 里播出的帧数/节奏与离线预览不一致、脚点与世界尺度不符：先检查 `.tres`、当前时间线和角色绑定，不为单个角色增加 `BattleModel` 特判。
- 最终报告至少写出候选与 Resource 路径、12 组动作各自的分镜/有效帧数/时长、循环/复位标志及选择理由、**角色设定身高、选定格宽高（328×256／384×288）与每次多帧 Sheet 的 C×R 格数/安全边距/拆格与零越界结果**、最终 Atlas 布局和逐动作有序绝对帧索引、脚点与根位移异常、实际执行的 Godot 预览；未导入或尚未经 Godot 实速检验的动作明确标记 candidate。不得把未执行检查写成通过。
