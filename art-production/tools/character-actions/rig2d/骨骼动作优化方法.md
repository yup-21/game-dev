# 手臂发僵怎么改

先挑一组行走和一组直刺做对照。固定部件图集、骨长、相机和地面根点。每轮只改一组参数，分别看骨架和角色预览，确认原因后再扩到其余动作。

## 先定位僵硬的位置

| 画面现象 | 优先检查 | 调整方法 |
| --- | --- | --- |
| 两臂跟着躯干像整块一起晃 | 上臂、前臂和手的角度峰值是否落在同一帧 | 把上臂、屈肘、手腕分成三条曲线，错开峰值。 |
| 手到位了，肘却突然翻到另一侧 | `chain_fit.<side>_arm.bend`、`joint_error_px` 和 `reach_correction_px` | 缩短过远的目标，避开锁肘。在几乎伸直的区间，用相邻两帧连续的肘侧作为约束。 |
| 肘正常，袖口在肘上折成尖角或露缝 | 部件的肘锚点、叠放深度、肘袖口转角 | 用同一张角色帧先核对关节，再调整袖口跟随权重或局部纹理。 |
| 刺出有力，收剑像整体倒放 | 握点和剑尖有没有各自的节奏，左手是否也同时回到戒备 | 先收肘，剑尖稍留在原方向，随后回落；空手再晚一点回正。 |
| 只有持剑腕像折断，或剑看似从手里滑出 | `wrist_angles_degrees.right.relative_extension`、`sword_grip_error_px` | 先让前臂顺着握剑方向，再调剑角；同时核对实际握点和剑柄像素。 |

固定帧率只能改变播放速度。放大腕位会连带改变屈肘和剑路。先找出峰值同步、关节越界、剑腕耦合或袖口接缝中的具体原因。

## 行走和跑步

1. **先定落脚相位。** 从右脚落跟起步，依次排出接重、越过支撑脚、蹬地和另一脚落跟。跑步另标两段腾空。保持承重脚的跟、掌、趾点在世界坐标对应同一足印。世界位移记录在 `world_root_offset_m`，画布的 `root_offset` 继续为零。
2. **先画上臂，再加屈肘。** 使用固定长度的前向运动学（FK），让右脚前伸时右上臂在后、左臂在前。顾清霜行走可从右上臂 ±15–20°、左上臂 ±20–27° 的摆幅试起，角度围绕自然垂臂姿态变化。把屈肘峰值放在上臂之后约 0.08–0.15 个周期。空手腕相对前臂再摆 5–12°，峰值略晚于肘；持剑腕幅度应更小，以剑尖不扫地为准。这些是试调起点。
3. **按部位分段缓动。** 摆臂到反向端点时速度降下来，中段穿过体侧时较快。先让躯干和肩随承重变化，肘腕再跟上。上臂角和屈肘角可用相位错开的正弦，或用保斜率的样条。避免逐帧交替改变肘的弯曲方向。
4. **采样看关键点。** 顾清霜例用 12 张 / 960 ms 行走、10 张 / 580 ms 跑步。先把帧留给落跟、承重最低点、脚尖离地、腾空或单脚通过、下一脚落地。中间隔可长可短，遇到手腕或脚尖换向就把帧移到换向附近。末帧直接接首帧，循环中不要复制首帧占一格。

## 直刺和其他攻击

1. **先画五个事件。** 戒备 → 预备与收肘 → 发力到有效姿态 → 惯性与卸力 → 戒备。先标脚的承重和躯干动作，再给出右手握点、剑角、空手腕的曲线。一次先只改准备、有效和回收这几个关键姿态。
2. **快慢有别。** 顾清霜 v6 直刺在 165 ms 进入收肘蓄势，335 ms 到有效刺，380 ms 到最远点，445 ms 开始明显回收，700 ms 恢复戒备。可以用三次缓动减慢蓄势和末段恢复，有效段单独提高速度。不要用对称的一条缓动让蓄力、出招和收招等速。下劈与横扫换成各自的剑尖弧线，保留其自身的承重切换。
3. **同时解握点与肘。** 当前侧视坐标中，屏幕右方是 x 正，向下是 y 正。先设目标握点和剑角；右手的方向由剑角和握姿偏角得到。腕目标 = 握点 − 5.5 px × 手的单位方向。用两段定长逆向运动学（IK）从实际肩口解到腕，肘点参考作者骨架并保持弯曲侧。顾清霜右臂长 34 + 28 px，左臂长 33 + 26 px。若肩到腕逼近总长，先把目标拉回约 1–2 px，或让躯干和肩合理前送。别拉伸上臂来补够触点。
4. **剑尖和手不能各走一套。** 顾清霜的剑从握点到剑尖固定 90 px；按握点 + 90 px × 剑方向回算剑尖。画出相邻帧剑尖的位置检查弧线。直刺有效段的剑尖要在近水平的短线上推进，收肘后再落下。逐帧检查刃尖不触地、出画面或穿过自己的支撑腿。
5. **回到共同戒备。** 需要回归戒备的动作，核对首末局部肩、肘、腕、握点、剑角和脚接触。世界位置可以不同。肩偏移和持剑腕附加角如有设置，也需在首末回到共同值。倒地按独立的终止姿态处理。

## 修改入口和检查方法

在项目的动作清单中按时间修改字段。按[使用说明](README.md)用[生成2D骨骼动画.cmd](生成2D骨骼动画.cmd)的单动作入口生成独立输出。顾清霜 v6 行走和直刺骨架可在 [pose_templates](https://github.com/yup-21/pose_templates/tree/main/rig2d/gu-qingshuang-v6/motion) 中参考，批处理入口为 [run_workflow.py](scripts/run_workflow.py)。

| 输入 | 渲染器如何使用 |
| --- | --- |
| `rig_pelvis_px`、`rig_torso_lean_degrees` | 放置、旋转躯干。左右肩从躯干部件锚点得到。 |
| `authored_keypoints_coco18` | 左腕是空手目标。左右肘给 IK 弯曲方向和对照位置。持剑腕由握点和手方向求出。 |
| `weapon_geometry.grip` / `tip` | 定义握点和剑的方向。右手、剑和剑穗跟随解出的实际握点。 |
| `rig_left_hand_angle_degrees` | 左空手在画布上的绝对角度。渲染相对前臂限制为 ±35°。 |
| `rig_head_counter_degrees`、`rig_secondary_degrees`、`rig_tassel_sway_degrees` | 分别是头部反向补偿、衣发次级摆动和剑穗摆动。用来增加滞后感。 |
| `parts.json` 的 `elbow_cuffs` | 在上臂、前臂之间给肘袖口插值。更适合修接缝。 |

独立工作流增加了两个可选输入，v6 样例沿用已有的关节动作，省略这些字段时效果与原求解一致：

- `rig_shoulder_offset_px` 接收 `{"left":[dx,dy],"right":[dx,dy]}`。每侧位移长度最多 6 px，先在躯干局部轴上偏移肩口，再随躯干旋转。可从前送 1–3 px 开始试。改完肩口后重新解肘腕；位移过大时回看肩袖是否出现裂缝。
- `rig_right_hand_offset_degrees` 是剑角和基础握姿角之外的附加角，限制 ±12°。先试 ±3–6° 的腕部缓冲。保持 `weapon_geometry.grip` 不变时，渲染器按新手方向重算腕目标，剑仍锁在同一握点。改完检查实际腕角和可达性。

上臂曲线、屈肘滞后和剑尖缓动都要编进各帧清单。渲染器会按坐标求解和放置部件，停留时间或 FPS 不会自动生成这些轨迹。肩袖可变形蒙皮、根据运动自动选择采样帧属于后续设计方向。

建议逐项比对修改前后：

1. **看曲线。** 把上臂、前臂、腕和剑角按 `time_ms` 对齐，角度用最短角差跨过 ±180°。相邻位移除以间隔毫秒再比较。走跑看首尾接缝是否突然加速；攻击保留有效段应有的速度峰值。
2. **看回执。** 在 `receipt.json` 核对左右臂 `chain_fit`、实际剑握点、腕角、肘袖口角。新版本的 `reach_correction_px` 和 `sword_grip_error_px` 应接近零。若肘角在伸直附近换号，按邻帧连续性和角色轮廓复核。透明边距仍按四边至少 8 px 检查。
3. **看实际播放。** 等比例并排看旧、新两版，先看原速，再只逐帧看关节翻转、脚滑和握持异常的位置。GIF 有 10 ms 时间刻度，精确时序以动作清单为准。几何检查通过后还要看衣袖遮挡、实际鞋底接触和出招读感。

已有实测示例可作为量级参照。顾清霜 v5→v6，行走左/右腕横向范围从 48.43/35.85 px 到 51.38/38.41 px，骨盆起伏从 4.5 到 6.8 px；直刺实际持剑腕相对前臂的最大夹角从 41° 到 34°。这是从动作清单和 Blender 回执得到的几何对照，画面的自然度仍需逐动作判断。
