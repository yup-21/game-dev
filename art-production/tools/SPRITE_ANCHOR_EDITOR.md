# 精灵帧固定点标注与自动排布编辑器

入口：[sprite-anchor-editor.html](sprite-anchor-editor.html)（下载该文件，双击即可用现代 Chrome / Edge / Firefox 打开；无需 Python、服务器或外部 CDN，所有图像均在本机浏览器处理）。

这是 **candidate 美术制作工具**，不是游戏运行时编辑器，不修改 Godot 中当前使用的 \`.tres\`。

## 使用方法

1. 输入动作名，例如 \`idle\`、\`move\`、\`attack\`、\`guard\`、\`hit\`、\`evade\`、\`skill\`、\`combo\`、\`ultimate\`、\`defeat\`。
2. 选择透明 PNG/WebP 母图，输入真实行列数，点击「拆格并加入动作」。支持只取其中一行，例如 v05 的 \`move\` 源图使用 **8 列 × 4 行，只取行 1（从 0 开始）**。也可以一次选择多个独立 PNG/WebP 帧，按文件选择顺序加入当前动作。
3. 点击左侧帧缩略图，选择「后脚承重 / 前脚承重 / 地面接点 / 躯干触地」等类型，直接点击图像中的真实支撑接触点。**复制上帧点只生成待复核点，不算人工确认。** 可导入旧 \`foot_annotations.csv\` 继续修订。
4. 将每帧都标记后，调整「透明边距」（默认 24px）和 Atlas 列数（默认 8），点击「计算统一支点并重新排布」。
5. 在动画预览中查看位移与停顿，下载 PNG、CSV 和离线 JSON。素材保持 \`candidate\`，在 Godot 中进一步播放验收后再决定是否接入正式 \`.tres\`。

## 重排原理

对第 i 帧：

- 原格内标记固定点 \`A_i=(ax,ay)\`；
- 在 Alpha 阈值检查得到主体边界 \`B_i=(xmin,ymin,xmax,ymax)\`（边界末端为 exclusive）；
- 汇总所有帧主体相对固定点的最左、最右、最上、最下范围，统一确定目标固定点 \`T\` 和格子宽高；
- 将该帧原始像素平移 \`(T.x-ax, T.y-ay)\` 到新格子，目标点误差应为 0；
- 所有帧采用**同一个格子大小和相同目标点**，每帧主体距四边至少指定边距，邻格主体的净间距至少两倍边距；
- **不对任意单帧单独缩放，不拉伸、不强行居中、不偷偷裁断**。如果过大超过安全画布限制，提示按动作分批导出。

这样能解决因每帧居中裁切、脚底高度不一而引起的图像坐标抖动；但固定点本身必须正确。行走交替换支撑脚和部分攻击的根节点移动，还必须由 Godot 动画与时间线驱动，不能把每帧都对到同一个世界点后断言物理上无脚滑。

## 导出格式与现有生产流程

- \`sprite_aligned_atlas.png\`：无损原像素 RGBA Atlas。后续在 Godot 的 \`WuxiaActorAnimationProfile\` 中使用对应列数、行数、索引与 \`feet_offset\`，经人工验收后才能替换 in-use。
- \`foot_annotations.csv\`：字段 \`action,frame,x,y,reviewed,source_edge_flag,anchor_type\`，其中 x/y **相对于原始源格**，和 \`rebuild_shen_v05.py --annotations ...\` 的前六字段兼容。脚点经人工点击才标 \`reviewed=1\`，未复核或缺失则为 0；请勿直接把未复核点当成批准结果。
- \`frame_contract.json\`：离线动作索引、尺寸、源格内固定点、目标点、人工复核标记。不是新的游戏运行时定义，正式配置仍以 Godot 原生 Resource 为准。

**注意**：现有 \`rebuild_shen_v05.py\` 自己带有逐帧缩放以塞入固定 768×320 格子的逻辑。用编辑器导出的 CSV 回灌它，只能复用手工脚点，不能保留本工具「所有帧原像素不缩放」的保证。需要保持该保证时，直接使用本工具输出的 Atlas PNG，并按输出 JSON 配置 Profile；不要让脚本重新逐帧压缩。

## 告警与限制

- 对 Alpha 非透明像素触及源格任一边的帧显示红色警告，可能存在截断或混格。重新排布只能保护现存像素，不能补回断剑、断袖。
- 全透明格或任意未标点帧禁止生成排布；\`reviewed=0\` 的已有初始点允许生成候选，但会在报告中标记未复核数量。
- 使用浏览器画布编码 PNG；图集尺寸不得超过任一轴 16384px 或 9000 万像素。大量帧应按动作分包。
- 暂不提供跨帧骨骼变形、自动间帧生成、根运动提取、自动修复原图或 GIF 导出；页面内提供当前动作循环 FPS 预览。
- 完成后请在 Godot 1600×1000 和 1440×900 视觉复核支点、单手剑数量、动作流畅性、剑尖完整性与世界尺寸。
