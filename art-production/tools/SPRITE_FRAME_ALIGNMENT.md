# 逐帧缩放与脚点对齐

在 **Art Production → 角色动作 Atlas → 自由装配** 中添加源图。用「微调的格号」选中要编辑的格位，再拖出任意裁切矩形，或沿轮廓描边去除相邻内容。

1. 设置当前帧的等比缩放倍率。`1` 使用原有的共同归一比例，其他值叠加在该比例上，仅作用于当前格位。
2. 将源图交互工具切到「点击当前格内的脚点」，在当前帧的裁切区域内点击逻辑脚点。该帧会对齐到输出画布横向中心、底边上 16 像素的位置。普通档为 `(164, 240)`，高个档为 `(192, 272)`。
3. 在「当前格输出预览」中检查比例和落脚线，无需先把这帧加入动作。点选脚点会清零该帧的输出偏移，此后可以重新微调。清除脚点可恢复原有的定位方式。
4. 确认导入后，逐帧比例和脚点与裁切、蒙版、输出偏移一起存入源候选 Resource，沿用导入事务和撤销。原生 SpriteFrames 继续保存最终帧序及播放参数。

超出画布的透明补边会去掉，角色、武器等有效像素必须完整保留。原始选区与输出帧依然执行透明边距检查。若修改裁切后脚点落到矩形外，需要重新点选。手工倍率用于校正不同来源的实际比例，校正后仍按角色制作规范检查相邻帧身高和动作连续性。
