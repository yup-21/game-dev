# 沈长风 Godot 原生 2D 骨骼小规模验证

## 目的

验证现有沈长风侧身战斗素材是否可以在不替换正式精灵帧系统的前提下，快速转成 Godot 原生 `Skeleton2D + Bone2D + AnimationPlayer` 表现，并比较动作连续性、制作成本与后续扩展空间。

## 范围

- 仅新增隔离原型场景，不修改 `WuxiaCharacterDefinition`、正式 `WuxiaActorAnimationProfile`、战斗状态机或攻击判定。
- 使用现有侧身待机帧（frame 1）作为主体来源。
- 为避免在验证阶段复制或重画美术，使用 `AtlasTexture` 对现有图集做非破坏式拆件。
- 拆件类别：头、躯干、后臂、前臂、后腿、前腿、衣摆、剑。
- 当前侧身待机帧中的剑与身体重叠，因此剑使用同一现有图集中的 attack frame 7 的细长剑身区域作为验证部件；没有引入新绘制素材。

## 骨骼层级

```text
Skeleton2D
└─ Hips
   ├─ Spine
   │  ├─ Head
   │  ├─ ArmBack
   │  └─ ArmFront
   │     └─ Sword
   ├─ LegBack
   ├─ LegFront
   └─ Skirt
```

所有动作只驱动 Bone2D 的 rotation，不移动 `Rig` 或 `Skeleton2D` 根节点，因此世界脚点基准保持固定。

## 动作

| 动作 | 时长 | 循环 | 验证重点 |
| --- | ---: | --- | --- |
| idle | 1.20s | 是 | 呼吸、头部与衣摆细微摆动 |
| walk | 0.80s | 是 | 双腿反相、双臂反相、衣摆跟随 |
| attack_sword | 0.58s | 否 | 蓄力 → 挥剑 → 收势 |
| guard | 1.00s | 是 | 抬臂、竖剑、轻微受力呼吸 |

场景内提供四个按钮，也可以按数字键 1–4 切换。

## 比例尺

原型读取现有侧身帧透明包围盒，并按项目共享 `CombatScale.actor_height_pixels()` 自动缩放。当前统一规则下普通角色目标可见高度为 200px，因此不会为骨骼原型引入第二套角色尺寸。

## 已知限制

现有图是完整人物姿态，不是为骨骼绑定绘制的分层 PSD/PNG。袖子、长发、衣摆、手臂、剑鞘互相遮挡，矩形 Atlas 区域只能近似分件；当 Bone2D 旋转幅度较大时，会出现切口、重复像素或原本被遮挡区域缺失。

因此本原型只用于回答“骨骼动画工作流是否值得继续”，不能当作正式可交付角色美术。若验证通过，正式制作应重新生成/绘制真正独立透明层，并为上臂/前臂、大腿/小腿增加更细骨骼。
