# 沈长风 Godot 原生 2D 骨骼小规模验证

## 目的

验证现有沈长风侧身战斗素材是否可以在不替换正式精灵帧系统的前提下，快速转成 Godot 原生 `Skeleton2D + Bone2D + AnimationPlayer` 表现，并比较动作连续性、制作成本与后续扩展空间。

## 范围

- 仅新增隔离原型场景，不修改 `WuxiaCharacterDefinition`、正式 `WuxiaActorAnimationProfile`、战斗状态机或攻击判定。
- 使用现有侧身待机帧（frame 1）作为主体来源。
- 为避免在验证阶段复制或重画美术，使用 `AtlasTexture` 对现有图集做非破坏式拆件。
- 拆件类别：头、躯干、后臂、前臂、后腿、前腿、衣摆、剑。
- 当前侧身待机帧中的剑与身体重叠，因此剑使用同一现有图集中的 attack frame 7 的细长剑身区域作为验证部件；没有引入新绘制素材。

## 骨骼层级

```text
Skeleton2D
└─ Hips
   ├─ Spine
   │  ├─ Head
   │  ├─ ArmBack
   │  └─ ArmFront
   │     └─ Sword
   ├─ LegBack
   ├─ LegFront
   └─ Skirt
```

所有动作只驱动 Bone2D 的 rotation，不移动 `Rig` 或 `Skeleton2D` 根节点，因此世界脚点基准保持固定。

## 动作

| 动作 | 时长 | 循环 | 验证重点 |
| --- | ---: | --- | --- |
| idle | 1.20s | 是 | 呼吸、头部与衣摆细微摆动 |
| walk | 0.80s | 是 | 双腿反相、双臂反相、衣摆跟随 |
| attack_sword | 0.58s | 否 | 蓄力 → 挥剑 → 收势 |
| guard | 1.00s | 是 | 抬臂、竖剑、轻微受力呼吸 |

场景内提供四个按钮，也可以按数字键 1–4 切换。

## 比例尺

原型读取现有侧身帧透明包围盒，并按项目共享 `CombatScale.actor_height_pixels()` 自动缩放。当前统一规则下普通角色目标可见高度为 200px，因此不会为骨骼原型引入第二套角色尺寸。

## 已知限制

现有图是完整人物姿态，不是为骨骼绑定绘制的分层 PSD/PNG。袖子、长发、衣摆、手臂、剑鞘互相遮挡，矩形 Atlas 区域只能近似分件；当 Bone2D 旋转幅度较大时，会出现切口、重复像素或原本被遮挡区域缺失。

因此本原型只用于回答“骨骼动画工作流是否值得继续”，不能当作正式可交付角色美术。若验证通过，正式制作应重新生成/绘制真正独立透明层，并为上臂/前臂、大腿/小腿增加更细骨骼。

## 本轮视觉验收标准

这仍是技术原型，标准分为“必须通过”和“允许存在的素材限制”。

必须通过：

1. **脚点稳定**：四个动作中人物脚底基准不能整体上下漂移；行走允许腿部摆动，但 Rig 根节点不得离开基准线。
2. **动作可读**：不看文字也应能区分待机、行走、出剑、格挡。
3. **侧身方向稳定**：动作过程中不能出现类似旧待机帧错误那样的正面/侧面来回切换。
4. **身体重心连续**：相邻关键帧的躯干、头部、双腿旋转应连续，不允许瞬移式跳变。
5. **攻击节奏完整**：出剑必须能看出蓄力 → 有效挥出 → 收势三个阶段。
6. **格挡姿态明确**：剑与前臂应形成明显防御姿态，不能与普通待机混淆。
7. **统一比例**：骨骼版可见人物高度应与左侧原始参考保持约 200px 的项目统一角色尺度。

允许存在、但必须记录：

- 由于当前原图不是独立透明分层素材，肩袖、衣摆、手臂交界可出现矩形裁切边缘或重复像素。
- 原图中被躯干/袖子遮挡的肢体区域无法凭现有像素恢复。
- 剑部件取自现有攻击帧，和侧身待机主体并非真正同一张分层原稿，因此连接处只用于技术验证。
- 本轮不以“达到正式角色美术质量”为通过条件；判断目标是 Bone2D 工作流是否明显优于继续修 24 帧图集。


## V2：使用专用拆件素材重新验证

V1 的视觉验收判定为不合格。失败原因是把完整人物帧按矩形区域裁切后直接挂 Bone2D，素材本身缺少被遮挡区域、关节重叠和独立衣摆/头发，因此旋转后不可避免出现纸片感、重复像素和切口。V2 不再沿用该拆法。

V2 使用本轮新生成的两套专用素材：基础拆件表 + 动作换件表。验证实现采用：

- 人体主结构：`Skeleton2D + Bone2D`。
- 长发与三片衣摆：`Polygon2D`，每片使用两根骨骼的顶点权重，验证柔性变形而不是刚性旋转。
- 待机/行走：主要依赖骨架和 Mesh 权重。
- 出剑：切换攻击躯干、挥剑手臂+剑、动态头发、动态衣摆和两条攻击腿附件，再用 AnimationPlayer 驱动整体蓄力/挥出/回收。
- 格挡：切换更紧凑的格挡躯干和双手持剑附件。
- Rig 根节点继续锁定世界脚点，并统一到项目 200px 可见角色高度。
