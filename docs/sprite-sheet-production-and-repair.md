# 战斗角色精灵图：简化造型、脚点和修图规范（2026-11-02）

本规范用于 **2D 战斗/剧情动作模型**，不降低角色立绘精度；现有运行时仍使用 Godot 原生 Resource。这里仅规范素材制作与校验，不引入第二套素材状态系统。候选可多个，使用中仅一个；来源只保留提示词和对应 resource。可用旧素材不强制返工。

## 1. 画风

* 战斗模型采用简练国风手绘 2D（非精细立绘缩小），以外轮廓、配色与动作清晰为第一优先级。
* 角色辨识锚点：发型/头饰、服装主辅色、显著的衣服轮廓、标志性武器、至多两件关键配饰。
* 去掉小面积刺绣、复杂花纹、多层高光、密集皱褶、过细刀剑装饰；保留可视尺度能看清的色块分层。
* 同一角色所有帧保持身高、头身比、服装长度、手持武器尺寸基本一致。站立与移动的躯干轮廓不得忽大忽小。
* 战斗默认 **侧面三分之二/侧身站姿**，看向敌方；正面立绘不能替代侧身战斗待机。左右翻转前先检查武器手和非对称服饰。

## 2. 动作帧生成与导出

* **优先独立透明 PNG 帧**（每动作一组），后按既有项目图集和 Resource 定义装配；禁止把多帧连在一幅画里再凭视觉等分。
* 图集已有的帧宽、帧高、列数、行数、动作顺序必须从实际 Resource/导入器读取；未完成核对前不可另定一套数字。已有 6×4 资源仅在对应绑定确认为 6×4 时按此切分。
* 每帧的画布大小、角色脚点 (ground contact)、身体比例与镜头固定。角色的**站立接地点**放在画布底部统一内缩约 4–8% 高度的位置，留有透明边距；不以衣摆/剑尖的最低像素自动代表脚点。
* 人物全身、兵器、头发、袖摆全包含在当前帧内，四周建议留出 5%–10% 的安全透明空间；挥剑幅度大时宁可采用更大统一画布或单独 VFX 图层，绝不可跨入相邻帧。
* 所有帧均透明背景（完整 alpha）；不生成地面、阴影板、UI、文字、格线、分隔线、帧编号或另一人物。
* 同动作的连续帧保持镜头、朝向、落脚位置与角色体积稳定，变化来自肢体动作而非整体漂移。待机呼吸幅度小，避免左右摇摆与头部转正/转侧交替。
* 移动动画允许脚步推进，但导入时仍以统一脚点为定位锚点；角色世界位移由游戏负责，不在循环素材里让整个人一直平移。

## 3. 生成提示词模板（复制并补齐方括号）

**中文正向提示词**

> 中国武侠 2D 游戏战斗角色动作帧，简洁清晰的国风手绘动画风格，非像素画，角色：[角色名与关键身份]；识别特征：[发型、服装主辅色、标志性武器、关键配饰]。固定侧身/三分之二侧身视角，面向右侧战斗姿态。动作：[动作名] 的第 [序号] 帧，共 [总数] 帧。保持同一角色的头身比例、身体高度、服装形状和武器大小一致。固定镜头，全身完整位于单张透明 PNG 画布内，双脚接地点保持统一基线，脚下保留透明安全空间，所有四边保持安全透明边距。简化布料纹理与装饰，强调动作剪影、重心和武器轨迹。无背景、无地面、无阴影板、无文字、无图集格线，单帧单角色。

**反向约束**

> 精细立绘缩小、过度繁复刺绣、复杂纹理、过密线条、角色比例变化、角色大小变化、远近镜头变化、正面战斗站姿、左右摇摆代替呼吸、身体截断、脚超出画布、衣摆/武器侵入相邻帧、多个角色、多个动作混在一帧、白底、背景、投影底座、网格线、帧标签。

如使用无法保证严格几何布局的图像生成模型，应**先生成独立动作关键帧并修图**，确认尺寸与脚点后再拼接图集；不将提示词视为裁切正确性的证明。

## 4. 修图工具

打开 [离线精灵图脚点修正工具](../../tools/sprite-sheet-editor/index.html)（也可以下载 HTML 后双击打开，不需要网络或 Godot）。

1. 载入现有 PNG，填入其真实列数与行数（工具要求整除宽高）。
2. 点击某格查看单帧，使用偏移输入或键盘方向键移动该格画面；Shift + 方向键为 5px。
3. 点击「自动统一脚底」可做粗校准，但它按每格内**最低不透明像素**判断：衣摆或长剑低于鞋底时需要手工调整。
4. 播放检查角色是否跳动、缩放或旋转；导出 PNG。JSON 偏移文件仅用于修图记录，不作为游戏运行时资源。
5. 在 Godot 中沿用现有导入器/绑定替换图集，然后在战斗场景检查动作朝向、脚点、格内安全范围和世界尺寸。**不直接覆盖正在使用的素材**，通过现有候选→使用中流程切换。

**限制：** 工具只能移动每格当前已包含的像素，并按格裁切以防跨格输出。源图若已有身体被切断、像素跨入相邻格，或图像生成时多帧混画，无法自动还原丢失内容；应回到逐帧源文件修复或重新生成。

## 5. 最小验收

1. 帧尺寸与原生 SpriteFrames/AnimationPlayer/atlas 定义匹配；列、行、动作映射不能凭猜测填写。
2. 逐帧没有非预期裁切；脚底基线基本一致，角色脚下有安全透明边距。
3. 战斗待机固定侧面朝向且无大幅左右摆头；走路循环、攻击、格挡、受击至少逐一预览。
4. 关键连续动作不存在整个人瞬间拉伸/缩放或大幅瞬移；战斗世界中的模型体型和站位以真实场景再次验证。
5. 若仍发生脚趾越界，先定位是源图切格错误、脚点锚定错误，还是 Sprite2D frame/hframes/vframes、region 或 AnimationPlayer 取帧问题；不要通过扩大整体角色缩放来掩盖。
