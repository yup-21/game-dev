# 序幕 V2 · 暮秋荒庙：偶遇残镖与雨夜逃亡

> **正式执行稿**。本稿替代旧版《暮秋荒庙 · 宿命传承》中的序幕叙事及角色关联。Godot 正式入口是 `demos/changfeng-battle/scenes/prologue/prologue_exploration.tscn`，对白由 `data/native/stories/prologue_chase_story.tres` 驱动。旧资源仅供历史回归测试。

## 已定叙事原则

- 沈长风是靠护路、送信糊口的**江湖散人**，没有已确认的秘密血统、灭门宿命、隐盟关系。此行顺道为乡里旧识捎家书去平江府，不是受任何势力安排来接卷。
- 严守诚与沈长风此前互不相识。主角本可置身事外；严经过**两次护送和两场追兵战斗**，才愿意把手中的无名残卷托付给他。
- 韩啸只是**受命执行截镖和灭口的现场头目**，并非幕后黑手。他此时**完全不知道残卷或关键物品的存在**，更不知道镖车里究竟有什么值得重视；他绝不在序幕与主角见面或交手。先后出现两名、三名普通鬼面探子，最后只有一名守在溪谷出口的哨探。
- 严已身受重伤，无法与追兵正面缠斗；留守是因为他比主角更懂追兵的搜山路线、镖车交涉口令，凭身份与诱饵**争取时间**。结局不确认生死。
- 截镖队本来只想杀掉镖队及目击者，**不是在序幕追寻残卷**。部分探子可能见过一个衣帽遮脸的陌生剑客，但不知姓名、真实面容或去处，也没有人看见残卷交接。雨水冲去足迹，延缓但不等于永久消除后续追查。
- **废弃主角寿元／暗伤倒计时**；序幕只出现无名“残卷”，**不透露完整书名**。初醒机制仅为**洞察当前敌方手牌**，高阶推演留给后续剧情。

## 主角个人动机

沈长风出身江南寻常乡镇，习得的是谋生护路的基础剑术，并非预设名门嫡传。他带着乡里旧识托付的一封寻亲家书，准备在平江府西市找收信人，顺路碰碰护送、跑腿的活计。秋雨挡道，他才在官道附近废弃的山神庙生火歇脚。此时主角尚不知镖队、残卷与追兵的存在。

这封家书是**可在平江府继续完成的普通支线动机**，不能暗设成陷阱、秘密指令或上层组织的接头密函。主角的身份背景可以逐步通过往事、人际关系和选择补全，不必用惊天身世证明他有资格成为主角。

| 8 | 同一溪谷入口 | 继续逃离 | 雨水掩足迹、远见烟水渡船灯，转入现有平江府探索场景 |

## 动机与信息边界

1. 严不因身份、佩剑铭印或血统而“认主”或授卷。他选择沈长风，是因为看见他有退路仍两次护送、在自身能力边缘保护一个陌生人。
2. 严留守不是身负重伤却突然武力暴涨；以可能被搜山队认出的自己引开追索，与年轻人分头行动，是迫不得已的战术选择，不保证成功。
3. 追兵与主角交锋时光线昏暗、秋雨不断，主角兜帽遮面、战斗没有自报姓名。韩啸未接近现场、未见交卷，更不知道卷的存在。**劫镖后韩啸先如实向上级上报，连同查获货物交差；上级核对后发现缺少关键物品，才责令继续搜查。韩啸由此第一次怀疑严守诚或某个第三方带走了东西**，但上级未必告诉他那东西是什么。追查主角仍必须获得独立的新证据。
4. 只教玩家原生 `BattleModel` 的 **Insight/洞察手牌**，并不在序幕解释卷名、起源和“认主”机制，也不使用消耗寿元的成长代价。

## 工程制作边界

- 主线 Story：`data/native/stories/prologue_chase_story.tres`；三个 Encounter：`prologue_scout_wave1.tres`、`prologue_scout_wave2.tres`、`prologue_lookout.tres`。
- 正式流程从主菜单「初入江湖」进入原生四区场景；原来四区 QA 可独立启动，使用隔离的 `prologue_progress.gd`，不能让测试用的「返庙伏击」误触发正式剧情。
- 场景 `.tscn` 中编辑出生点、行走区域、交互标记；`.tres` 中改对话和战斗人数；`GameSession` 保留跨战斗阶段、选择及洞察状态。
- 战斗中途失败可从本场重试；救与不救从官道选择点重试。基础战斗胜负由原生 `BattleModel` 判定，不做剧情强行必赢。
- 雨夜的老镖头造型暂复用已入库受伤姿态图。鬼面斥候暂复用现有刀客图，需美术验收后在原生角色资源中替换；三场战斗目前共用现有 `rainy_bridge` 战场资产，后续可以单独制作各区战场。
