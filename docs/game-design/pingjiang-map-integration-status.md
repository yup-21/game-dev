## 当前阶段

**四区原生分层地图已连成可往返的探索测试路线。** 主菜单 `J · 平江四区` 从南门进入；WASD/方向键移动，左键设直线移动目标，靠近金色出口按 E 换区，F3 显示可走区，Esc 返回。鼠标目标仍为直接移动，绕过街角需分段点击或用方向键，本轮未引入新的寻路系统。
