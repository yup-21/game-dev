# 《长风浮生录：以武入道》游戏企划模块化文档库

> **核心定位**：水墨高武玄幻 · 战棋卡牌与即时交锋 RPG  
> **核心主题**：凡人以武抗仙 · 万古薪火不灭 · 破除残仙囚笼 · 破碎虚空登仙  
> **技术基石**：Godot 4.x 原生强类型 Resource 驱动（`content_manifest.tres`）

> **现行剧情规范 V2**：以[主线同步审查清单](mainline-v2-consistency-audit.md)、[序幕 V2](chapters/act-0-prologue-v2.md)与[第一幕 V2 任务链](chapters/act-1-pingjiang-v2.md)为准。第一幕 V1 至终章的旧详细分镜虽保留作素材，但含已废弃的灭门宿命、寿元死线及过早暴露残卷真名等内容，不能直接进入制作。
