## 1. 设计定位与边界

平江府是江南道第一幕的核心水都。城市表面为水陆双棋盘、商贾繁华的姑苏城；城西暗渠与地下鬼市、血炉暂保留为**候选远期副本空间**，不自动成为已确认的第一幕终战。现行主线按[平江 V2 任务链](chapters/act-1-pingjiang-v2.md)先完成家书与谋生、药膏取样、药材货运调查、证人和账本收集，再凭证据决定向外地延伸。

地图采用“城市区域拓扑 + 独立街区地图 + 街区内部连续卷屏 + 明确入口/出口跳转”，不制作可一镜到底的全城大图。版本一共规划 **16 个独立地图区域**：

- 城内 8 个室外街区，保持原企划 Screen_Center / West / North / NE / SW / East / SE / South 的功能和邻接关系。
- 4 个独立可进入的店铺箱庭，均为 1600×1000。
- 枫桥茶棚、城西暗渠、地下鬼市交易街、血炉密室共 4 个第一幕附属地图。

仅 PJ-01 至 PJ-08 属于“8 个主城街区”；PJ-I 为室内，PJ-X 为剧情/副本。城市总览只表示区域关系，不是角色行走底图。不存在一座真实历史城池对应多少世界像素的强制换算。

## 2. 统一尺度与运行原则

| 属性 | 统一设计值 | 说明 |
| --- | --- | --- |
| 逻辑视口 | 1600×1000 / 16:10 | 1440×900 仅为窗口缩放测试 |
| 世界长度 | 1 u = 80 世界像素 | 唯一来源为 scripts/combat_scale.gd，禁止在地图另定义常量 |
| 普通角色高度 | 200 世界像素 | Y 轴远近移动不得缩小人物 |
| 角色脚点占位 | 半径 24 世界像素 | 碰撞体独立于衣袖与兵器 |
| 横向街道纵深 | 推荐 280–400 px | 保持 DNF 式紧凑密度，可因场景合理变化 |
| 纵向主廊宽度 | 推荐 240–400 px | 上下方向连通，不旋转横图冒充纵图 |
| 同平面门洞 | 净宽 120–180 px；净高 256–304 px | 可通行净空需结合碰撞实测 |
| 场景层 | background、ground 必需；foreground、weather 按需 | 同尺寸、同原点、真实 Alpha，运行时不二次拉伸 |
| 地图切换 | 明确 zone_exit → target_scene_id / target_spawn_id | 双向入口独立、加载阶段验证，缺失引用报错 |
| 地图坐标 | 局部世界像素坐标 (0,0) 为左上角 | 出口、NPC、障碍、脚点与背景共用坐标 |

长图的“卷屏”发生在同一个场景内；跨 PJ 区域才进行连接点切换。当前可沿用完整画布贴图与相机跟随，**不假定已经实现流式分块加载**。美术可以分段制作，最终仍按完整世界尺寸输出同尺寸图层。

8 区合计 21,440,000 世界像素面积，等于约 13.4 个标准视口面积。这里的“视口面积”是美术工作量估算，不表示所有画面都是可行走面积。

### 3.1 区内细分制作

**PJ-02 十字路口**：单屏，中心保留相交的横向路带与纵向路廊，分别通往上/下/左/右四个区域。四向道路在同一可走地面上真实连通。推荐 P0 先画清晰完整的地面与门洞，不烘焙比例尺、角色或 UI。

**PJ-03 临河主街**：按 X=0–1600、1600–3200、3200–4800 三段制作构图，再汇总为一张 4800×1000 的世界画布。西段为暗渠与河埠，中段为铁铺和药房，东段为茶棚商贩与回到十字路口的道路。连续移动只滚动镜头，区内不切换地图。

**PJ-05 府衙正街**：从南到北依次安排街巷生活界面、巡捕检查、府衙正门；1600×2400 为一个连续地图，横屏视口沿 Y 卷屏。既有 1600×4000 北街长巷测试资源继续作为 QA 验证素材，**不能自动视作正式府衙街场景**。

**PJ-01 南门水关**：纵向两屏世界，北接十字路，南接城外芦苇荡古道；水关入口提供可配置的渡船路线，连到枫桥茶棚/烟水渡方向。

**PJ-06 演武场**：两屏宽，分为教学区和擂台区；预留六人战斗的独立站位面和可移动障碍。GRID/FREE 的规则由 Map Resource 定义，视觉面积不能擅自改变战斗距离。

**PJ-04、PJ-07、PJ-08**：首版各一屏。住宅、园林和酒楼内部未来可另建区域，现阶段不额外占用 8 区预算。

## 7. 首张地图：PJ-02 四街十字路制作合同

- scene_id：pingjiang_crossroads
- 画布 / world_size：1600×1000，16:10，世界原点左上角。
- primary_axis：mixed，中心区域横向与纵向可走廊道真正相交。
- 四向出口的设计锚点（待 Godot 地面多边形复核）：
  - north：约 (800, 90)，目标 PJ-05 south。
  - south：约 (800, 920)，目标 PJ-01 north。
  - west：约 (90, 790)，目标 PJ-03 east。
  - east：约 (1510, 790)，目标 PJ-07 west。
- 推荐横向可走带 Y=620–940；南北纵廊推荐 X=640–960 并与横街汇合。地面多边形应覆盖“十字”并保持街角过渡无障碍；这些为设计锚点，不是未经验收的正式碰撞数据。
- 地标：中心“永安平江”牌坊；一侧说书茶棚；一侧悬赏告示；一处行商摊。绣坊、当铺门洞可与建筑立面结合，但应有明确独立入口。
- 相机：固定 1600×1000，无缩小世界素材、无夸张消失点透视。
- 风格：暮秋江南，粉墙黛瓦、青石板与水墨蓝灰，局部灯笼温金；国风手绘、可阅读的地面、真正的前景遮挡。
- 不在生成图内绘制角色、NPC、比例尺、浮动名称、UI、路面碰撞网格。
- 正式图层：background、ground 必需；foreground、weather 按需，所有使用的层以 1600×1000、同原点、真实 Alpha 输出。
- 候选目录：art-production/candidates/scenes/pingjiang_crossroads/；运行导入目标：demos/changfeng-battle/assets/imported/scenes/pingjiang_crossroads/。
- 绑定：WuxiaSceneArtProfile → WuxiaChapterSceneDefinition.scene_art / 战斗 WuxiaMapDefinition.scene_art（按实际入口）；不得用单张候选预览冒充正式绑定资源。
- 未经几何、透明、Godot 真实 GUI、权属与人工视觉审查，不覆盖任何已在用地图和 Resource。

## 8. 提交批次与验收

1. **设计设定 PR**：本文件，确立尺寸表、区 ID、邻接表、首张地图约束，不修改当前运行资源。
2. **首张美术候选 PR**：PJ-02 的概念母版、实际提示词及工作单；形成分层候选后检查画布/Alpha 与地面几何。单张概念图本身不等于地图可玩。
3. **首张 Godot 接入 PR**：经视觉确认后的 background/ground 等正式素材、原生 scene_art Resource、入口/出口、真实运行截图与校验结果。
4. **后续逐块 PR**：优先 PJ-03 / PJ-01，随后 PJ-05 / PJ-06 / PJ-07 / PJ-08 / PJ-04、店铺和剧情副本。一次聚焦一到两个相邻区域，避免无验收地覆盖大量素材。

### 明确非目标

- 不重写 BattleModel、GRID/FREE 规则或世界单位。
- 不把 4800×1000、3200×1000、1600×4000 既有测试图自动登记成正式平江府区域。
- 不在缺失素材时自动降级占位、旧单图或其他区域。
- 不把一张拼接概念全图当作运行时独立 background+ground。
- 不宣称已经完成动态切片流式加载、完整四向角色动画或 Godot 实机视觉验收。
