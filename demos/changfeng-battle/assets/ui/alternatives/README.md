# 备用 UI 美术：极简 CTB 集气轨道

本目录为试验性美术备选素材，**不会自动加载，也不替换正在使用的 HUD**。

## 资源

- `ctb_rail_minimal_v1.png`：原创图像生成的极简纵向集气轨道（PNG RGBA，1129×1393）。
- 设计关键词：黑铁细线、少量古金刻度、低调青玉端点、透明背景。
- **没有固定头像环或角色立绘**。角色头像必须由运行时独立节点渲染和移动。

## 使用约束

正式战斗界面仍使用 `../ornaments/ctb_rail.svg` 和 `../../../scripts/hd2d_ctb_rail.gd`。
该脚本从 BattleModel 的真实 gauge 读取进度，独立创建圆形角色头像及动态位置。

如果未来要选用这个备选纹理：
1. 先裁掉 PNG 左右的大面积透明留白，并检查透明边缘；
2. 仅把它用作轨道背景，不在图片中绘制固定头像环；
3. 保留脚本根据 actor gauge 放置头像的机制，出手/集气文案和高亮由运行时绘制；
4. 通过真实战斗截图和 CTB 回归测试后，才替换正式纹理。

来源：2026-10-30 原创生成的 UI 概念素材。此文件仅作备选美术参考，不包含卡面，也不修改角色、牌组或战斗逻辑。
