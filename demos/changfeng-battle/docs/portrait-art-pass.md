# 原创武侠角色立绘与动画资源接入规范

本阶段角色视觉方向为非像素、细腻手绘武侠风；HD-2D 仅用于斜俯视场景布局、光影与景深，不要求像素化。

## 角色资产

已生成沈长风（青墨剑客）与一名霜发佩刀护卫的原创立绘候选图。候选图仍需透明背景、边缘及授权归档验收，当前尚未纳入游戏运行资源。不得把单张立绘声称为完整逐帧动画。

正式导入路径建议为 `res://assets/characters/<id>/`，分别存放 `portrait.png`、`idle`、`walk`、`attack`、`guard`、`hit`、`combo` 动画资源。所有帧需要统一比例、脚底锚点、朝向与武器轮廓，Godot 导入时启用平滑过滤。对于暂缺动作使用现有动画回退，不能更改结算规则。

## 后续实现与验收

1. 先逐张检查 PNG alpha、人物剪影、发型服饰和武器一致性，再导出统一动作 atlas。
2. 序章追兵进入 `battle_hd2d.tscn` 前，先将场景从固定角色 0 的双人展示改为按 `GameSession.encounter_options()` 初始化；为每名 `PLAYER` 角色分别生成合法行动与可见手牌，并处理 `CLASH` 响应权。
3. UI 改为角色切换、CTB 行动序列、手牌扇形/横排、费用、目标高亮与连携层展示。所有操作只允许从 `BattleModel.legal_actions(actor_id)` 选择并调用 `request/submit`。
4. 通过多人剧情回归、连携和动画 ticket 测试，再进行 Godot 实机截图与性能验收。

此提交仅提供资源规范和接入计划，不代表上述实现已完成。
