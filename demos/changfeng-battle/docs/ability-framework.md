# Extensible technique infrastructure

This branch provides the first additive foundation for techniques independent of card instances: a bounded condition interpreter and a cross-ACTION technique state graph. The default technique catalog is empty, preserving existing V3 game data.

The next integration step connects technique nodes to the unified legal-action query, the cost pipeline and the existing attack/reaction resolver. This document intentionally distinguishes the graph infrastructure from the full event-driven follow-up system, which is not yet implemented.
