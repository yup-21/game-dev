# 多武学学习、装备与战斗切换

设计：**学习**不是**装备**。角色档案 `learned_schools` 是已掌握流派集合（可持有多套），`school_id` 是初始装备。导入战斗后，`CombatantState.learned_schools` 和 `school_id` 分别记录允许集合与当前状态；新增流派只修改档案，无需在代码里硬编码人物名称。

`CardSystem` 只加载参战角色已学武学的卡牌定义与连携，避免导入全部流派；`BattleModel` 中经 `CombatRules.raw_actions/validate` 允许行动方选择 `SWITCH_SCHOOL`，`CombatResolver` 执行实际换装，产生 `SCHOOL_SWITCHED` 语义事件，并调用 `TurnManager.end_action()` 消耗 CTB 行动。不能在交锋、动画 pending、敌人回合或未学会的流派上使用，也不能用旧 revision 请求重复切换。

安全性：切换先验证目标流派的牌组可装配，再移除该角色原卡牌实例、各区持有的手牌/牌库/弃牌/放逐和各方对该角色旧卡牌的记忆；新建12张流派基础牌并抽取5张；清除旧连携历史、用牌次数，重置就绪的额外技能阶段。**不会重置** HP、Qi、状态、基础属性、先天被动、队伍、位置或现有集气量（除了本次行动正常的 CTB 扣减）。

角色详情 UI 中按武学目录名称展示所有已学流派、标明当前所用，合法时可点击切换；右侧命令区只有一个「武学 · 切换 ▸」入口，不因学会多门武学而堆叠按钮。角色卡继续展示已学阶段技能和真实状态；未装备武学不能出对应武学卡。

无档案老版自定义战斗依然使用单一装备流派；未来存档可保存 `character_id`、`learned_schools` 以及当前装备 `school_id`，并统一交给角色成长系统扩展。
