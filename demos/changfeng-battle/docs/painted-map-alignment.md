# 按正式贴图校准战斗地图

当前 `data/maps/rainy_bridge.tres` 的 15×10 `painted_rows` 仍来自旧地形，**尚未与新版分层断桥贴图完成校准**。更换背景并不会自动改变移动范围、出生点或碰撞。

## 快速工作流（Godot 4）

1. 在 Wuxia Map Editor 中打开 `rainy_bridge.tres`，同时显示 `scene_art` 对应的背景、地面、前景叠加图。
2. 开启网格叠加。以桥面、道路边缘和人物脚点为基准，调整 `first_center` 与 `cell_size`，不要以图像外边框作为可行走范围。
3. 逐格标注桥面 `B`、道路 `.`，河水 `W`、岩石 `R`、竹林 `T`；河流、桥栏和悬空处必须不可通行。
4. 对照 `escort_ambush.tres` 的所有角色初始格，确保出生点是可行走格且互不重叠。
5. 运行战斗，按 **F3** 查看运行时网格。分别验证 GRID/FREE 的点击、移动和寻路不会进入河流。
6. 验证 `scene_art` 的全部图层尺寸都是 1600×1000，且背景、地面、前景共享同一像素坐标原点。

## 后续更高效的方案

现有 `WuxiaMapDefinition` 支持 `area_bounds`、多边形障碍和原生标记。对于手绘、非规则桥面，优先在原图上直接描绘可行走边界与障碍，再由 `MapBake` 派生 GRID 的 15×10 索引；FREE 继续使用多边形碰撞。这样换图时不必反复手工维护整张字符网格。

**不要直接把旧的 15×10 地形字符套在新画作上，也不要通过单纯放大背景掩盖碰撞错位。**
