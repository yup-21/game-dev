# Demo B：参悟、衍生三式与暗伤负面状态

以 Demo A 的剧情会话、3v3 遭遇和结算画面为基础。新机制使用原来的 `CardSystem` / `CombatResolver` / `BattleModel`，没有单独制作演示假的攻击效果。

## 游玩
- 序章获得《太虚引气残篇》后进入 `study.tscn`。
- 点击“参悟残篇”，本次会话解锁太虚套路，并把 `taixu_open` 起手式生成到剧情战斗玩家手牌；仅剧情遭遇适用，原本普通卡组与自由沙盒不变。
- 起手「探脉」**命中**时生成「流云」到手牌；「流云」命中再生成「断空」。两张后续招有各自 UID、parent_uid、root_uid；使用后进入 exile_pile 不再洗回牌库。每张衍生卡可最多跨自身 ACTION 保留两次。
- 这些招式在 `data/demo_cards.json` 中定义；初始牌组无需收录，也无需每张卡硬编码技能分支。
- 目标离开攻击覆盖区或攻击被打断时不会生成后续卡，遵循原有命中规则。
- 「暗伤」是持久负面状态，每层降低 **当前气血上限** 2 点（最多 3 层），不改变角色由体质决定的**基础最大上限**。
- 三层数值始终分离：`base_max_hp_u`（体质基础最大上限）→ `max_hp_u`（当前状态修正后的上限）→ `hp_u`（实际气血）。例如基础 20，暗伤 1 层，气血被限制为 18；若此时实际气血为 9，疗伤后恢复 20 上限，但实际仍为 9。
- 「疗伤休整」解除暗伤并恢复上限；「带伤追查」保留暗伤，后续战斗通过同一个 `StatusSystem` 应用该上限惩罚。之前救助镖头会留下剧情标记；追问劫镖者再追查，可得到追兵令牌线索。
- **序章不展示寿元、寿元倒计时和寿元消耗**；也不向玩家提前说明暗伤与长远生死代价的关系。该秘密留到后续剧情揭示。
