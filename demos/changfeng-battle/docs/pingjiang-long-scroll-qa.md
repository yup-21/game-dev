# 平江府主干道：DNF 式五屏双区滚动验证

这是 Demo 标题菜单中的**独立 QA 测试入口**，用于验证连续横向镜头和两张原生地图区域之间的双向衔接；不会更改现有序幕、战斗地图或 GameSession 正式流程。背景与地面为低保真原创 SVG 技术简图，并非正式美术。

## 从 Demo 进入

1. 使用 Godot 4.7.x 打开本目录的 `project.godot`，运行主场景（F6/F5 视项目设置；通常按 **F5**）。
2. 在《长风浮生录》标题菜单点击 **「P · 平江双区滚屏测试」**，或直接按 **P**。
3. 用 **WASD/方向键**控制沈长风、**左键**点击可走街面自动行走；**F3** 显示/隐藏每区可走多边形。
4. 从主干道 X=200 向右走，穿过 **X=4800** 的区域接缝进入「东市·续接街区」；再左行返回主干道。观察 HUD 的区域编号及“跨区次数”。
5. 按 **Esc** 返回 Demo 标题菜单；“新游戏”和“进入战斗”仍按原流程运行。

也可在编辑器单独运行 `res://scenes/pingjiang_scroll_qa.tscn`，无需启动主线。

## 地图拼接与镜头

| 原生地图区域 | 世界坐标 X | 原生美术画布 | 描述 |
| --- | --- | --- | --- |
| 主干道·临河水市 | 0–4800 | 4800×1000 | 第一张三屏长街 |
| 东市·续接街区 | 4800–8000 | 3200×1000 | 第二张独立双屏地图，含街铺、水道、石拱门 |

总世界宽度为 **8000×1000**（五屏），视口 **1600×1000**，两张资源同为 **80 世界像素/游戏单位**；角色标准高度 200px、脚点半径 24px。不拉伸背景，不在接缝传送人物，所有分层纹理通过各自区域的 `Node2D` 世界偏移拼接。

| 角色世界 X | 当前区域 | 镜头 X 偏移 |
| --- | --- | --- |
| 200 | 主干道 | 0 |
| 2400 | 主干道 | -1600 |
| 4600 | 主干道 | -3800 |
| 4800 | 东市（接缝） | -4000 |
| 4900 | 东市 | -4100 |
| 7800 | 东市 | -6400（总图最右钳制） |

每区仍拥有独立的 `WuxiaMapDefinition`、`WuxiaSceneArtProfile`、碰撞多边形和标记；接缝处在脚点跨越两区边界时同时检查两侧道路可走性，从而允许角色站在拼接线上，又不允许借接缝穿过街屋或离开路面。

镜头复用 `world_viewport_offset.gd`，跟随全局脚点滚动；鼠标目标在切换区域后仍按世界坐标逆变换。HUD 中的区域名、区域序号和跨区计数可用于目视验收。
