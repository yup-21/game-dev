# 平江府地图 QA：连接点换区与 4000px 纵向滚屏

本测试是 Demo 标题菜单中的独立入口，不更改序幕剧情、战斗、GameSession 和正式地图。新旧素材均为原创 SVG 技术简图，不代表正式美术通过人工批准。

## 进入与控制

1. 使用 Godot 4.7.x 打开 demos/changfeng-battle/project.godot 并运行主场景。
2. 点击菜单 **P · 平江双区跳转测试**（快捷键 **P**）或 **V · 纵向四千滚屏测试**（快捷键 **V**）。
3. **WASD/方向键**移动沈长风；**鼠标左键**点击可走地面设定移动目标；**F3** 显示/隐藏碰撞边界；**Esc** 返回标题菜单。
4. P：从主干道向右走到**(4600,790)** 的金色连接环，按 **E** 进入东市；角色将在东市的本地坐标 **(200,790)** 出现。在东市入口金色连接环按 **E** 可返回主干道。HUD 显示当前地图与跳转次数。
5. V：从南端 **(800,3700)** 按 W 一直走向北端 **(800,100)**，验证 Y 方向滚屏；点击屏幕中部街面也能检查鼠标逆映射。

## 地图结构

| 地图 Resource | 真实画布 | 滚动与连接 |
| --- | --- | --- |
| pingjiang_long_street_qa | 4800×1000 | 三屏横向；东口 street_end → 东市 |
| pingjiang_east_market_qa | 3200×1000 | 两屏横向；西口 east_entry → 主干道 |
| pingjiang_north_lane_qa | **1600×4000** | 四屏纵向，独立入口 V |

**两张横向地图不再拼成同一张 8000×1000 世界地图。** 运行时始终只加载当前区域的 WuxiaMapDefinition / SceneArtProfile / 碰撞与美术节点。连接由原生 WuxiaMapMarkerDefinition 的 zone_exit、target_zone_id、target_entry_id 元数据决定，靠近后按 E 触发，目标 Resource 与入口合法时释放当前区域并载入下一张。跳转会清空旧鼠标目标，并在目标地图本地坐标计算相机，既支持双向返回，也不会因踩在出生点立即自动反跳。

纵向地图是真实 1600×4000 的三层 SVG 画布，完整 Y 范围 0–4000；它不是竖屏游戏，也不旋转横图或把 4000px 压到 1000px。逻辑视口始终 **1600×1000**。所有地图采用 **80px/u、普通角色 200px 高、24px 脚点半径**。纵向街巷可走面为 X≈620–980、Y≈40–3960，不会根据屏幕上的颜色决定碰撞。
