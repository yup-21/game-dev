# 《长风浮生录》十套武学 V3 · 引擎适配与迁移清单

> 原包技术参考副本。当前模块化项目已完成适配，真实接口、取舍及运行验证见 [V3移植结果](../wuxue-v3-integration.md)；本页原型Engine接口不作为当前项目API。

> **真实代码 + JSON 内容包**。以《听风五式》V2 为基础做增量改造；本包不是用户原有正式工程的补丁。

## 设计范围

- 旧版 10 套 / 40 张单用途武学卡 → **10 套 / 20 张核心式 / 41 种使用方式**。同一张 CardInstance 每次只可选择一种 usage。
- 每套 2 种核心式，派生主动、攻击响应、防御响应等；观势/藏锋继续是角色被动，不重新做成卡。
- 兼容旧《听风五式》测试模式（默认选择），双方可以独立选择不同武学；每个选择构建 12 张牌的测试卡组。
- 采用 CTB 集气、全局时间回气、自由行动、有限四层 LIFO 连锁，主动招式间可触发 Combo。
- 保持四维公式：力道/身法/体魄/心神及原始 20 HP / 6 气上限 / 3 气初值。
- 没有加入完整架势条、实时动作帧、无界连锁，也未实现 RPG 剧情升级与战斗外角色培养。

## 通用效果语义（新增或明确）

| 效果 | 语义 |
|---|---|
| `deal_damage` | 创建一次根攻击，攻击前检查本次 usage 的射程和直线障碍 |
| `on_attack_hit` / `on_attack_miss` | 分别在真实命中（即使护体全挡）或落空后运行子效果 |
| `force_move` | 伤害结算后沿攻击源/目标连线尝试牵引/击退1格；目标格必须可站立 |
| `draw_cards` | 抽指定数量，保持 CardInstance 唯一 UID 和牌区流转 |
| `damage_if_status` | 命中并发现目标有指定状态时按层数加伤，可消耗状态 |
| `damage_if_shield` | 攻击方尚有护体时给本次攻击额外伤害 |
| `damage_if_low_hp` | 燃血费用支付后，低于设定比例时强化本次攻击 |
| `apply_status` | 可按 `stacks` 叠层，遵守统一 stack_limit 和 expiry |
| `once_per_action` | 标记的 usage 每角色本次完整行动仅允许一次，不可用另一副本绕过 |

## 状态时钟

- **凝势 focus**：最多 2 层，下次主动攻击宣告时全部消耗，每层 +1 伤害；不因 MISS 返还。最大 250 全局 tick。
- **封气 qi_seal**：持续 150 全局 tick，期间自然内息恢复速度减少 50%；**不**在角色起息时额外扣气。
- **灼痕 scorch**：最多 2 层，每 100 全局 tick 造成当前层数的气血伤害，再减少 1 层；不受角色集气速度影响。
- **露隙 opening / 明牌 hand_exposed**：继续沿用原五式 V2 定义；明牌覆盖观势/藏锋对抗，且已知手牌在持续期间保持已知。
- **护体**：存储为独立数值与绝对到期 tick，不混入常规状态层数。

## 牌组构筑

各套测试牌组共 12 张：旧五式公共卡 `tf_probe`×1、`tf_step`×2、`tf_guard`×2、`tf_change`×1，加本套两张核心式各 ×3。它们都是测试用镜像牌组，不代表最终 RPG 正式配卡。

## 代码接入与公开接口

```gdscript
const Engine = preload("res://scripts/tingfeng_engine.gd")
var combat = Engine.new()
combat.start(2026, {}, {"player": {"insight": 1}, "enemy": {"conceal": 1}},
    {"player": "wind_sword", "enemy": "saber"})

var visible = combat.view("player")
var options = combat.legal_actions("player")
if not options.is_empty():
    var req = options[0].duplicate(true)
    req.merge({"battle_id": combat.battle_id, "version": combat.version,
        "actor_id": "player", "action_id": "example-0001"})
    var response = combat.submit(req)
```

- `start(seed, attribute_overrides, passive_overrides, school_selection)`：最后一个参数为可选，不传默认双方《听风五式》。
- `view(viewer_id)`：针对观察者的情报过滤视图；AI 与 UI 不可直接把对手手牌真值读取进策略。
- `legal_actions(actor_id)`：包含 `card_uid + usage_id`；只能提交引擎返回的规范行动。
- `submit(ActionRequest)`：统一校验、支付费用、结算、更新版本与发出事件。
- `LegacySkillAdapter.resolve_legacy("wind_01")`：得到 `{card_id:"wind_flow", usage_id:"probe"}` 的迁移引用。

## 限制与已知取舍

- 原版《雁回掠锋》“先移后攻”和《雪尽无踪》2 格闪避已简化；前者改为单击，后者采用普通 1 格游身应变。
- 原《海门不动》“完全无伤则回气”暂未保留；应在未来基于 `HP_DAMAGED`、完美接招事件定义 TriggerHook。
- 远程只允许曼哈顿直线和通行格 LOS；无斜线、弹道曲线、多人队伍。
- 当前 AI 是规则合法的轻量策略；不执行长链搜索，可能不会每次选择最佳变招。
- 每种效果仍用已有引擎方法分派；后续正式工程可按 `EffectResolver / TimelineScheduler / VisibilitySystem` 进一步拆模块。
- 新武学数值是第一轮可测版本，尚未通过自动数值平衡、Godot 实战或实际人工试玩。
